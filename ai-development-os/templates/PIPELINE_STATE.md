# 当前阶段与接续凭证

每次只维护一个当前指针。阶段历史保留作证，续接先核对真实版本及最近消息。

| 项目 | 已核实的值 |
| --- | --- |
| 任务与最新要求 | 〔原话、来源，已处理的插入问题〕 |
| 模式、责任与边界 | 〔全程／单步／只接入，风险 R1 至 R4，审查者，唯一写入方，当前环境与预算〕 |
| 版本和入口 | 〔仓库、固定提交、制品摘要，工作区或归属范围〕 |
| 本轮决定与复验依据 | 〔任务编号、所选 A／B／C 和范围、原始契约位置、基线、最新候选、已关闭与待复验项〕 |
| 当前状态 | 〔未开始／进行中／待输入／已收口〕 |
| 当前阶段与首项未完成工作 | 〔阶段编号、路径或用例游标〕 |
| 最新可复用证据 | 〔E 编号、前提、清单和封存位置〕 |
| 独立可做的工作 | 〔事项〕 |
| 阻碍与恢复条件 | 〔缺什么、谁能决定、需要何种新证据〕 |

| 阶段与适用性 | 输入和候选 | 执行人与状态 | 证据或产物 | 未完、失效项与下一步 |
| --- | --- | --- | --- | --- |
| 〔00 至 15 中的适用阶段〕 | 〔输入标识〕 | 〔填写〕 | 〔编号或链接〕 | 〔填写〕 |

版本变化时保留旧记录，比较新旧对象、依赖、契约、数据和运行环境。在新候选上登记失效范围。
