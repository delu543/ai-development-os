# 03 · UI/UX 专项审查

用于已有交互界面、改版方案和真实界面验收。

```text
请按当前产品目标审查界面和体验。输入取自现有界面、用户任务、设计稿或设计系统、支持设备与约定版本。先核实应该观察的端和构建，列出关键旅程与状态。设计资料缺失时用已有产品的一致性作参照，注明依据。

在可访问的真实运行界面走完整流程，从发现入口、理解提示、操作到确认结果及恢复。覆盖正常、空、加载、超长内容、出错、禁用、权限不足等适用状态。检查信息层级、文案、导航、反馈、交互一致性、可撤销性与误操作代价。用实际支持的断点、缩放、横竖屏和语言检查遮挡、换行、触控与布局。对键盘顺序、焦点可见性、控件名称、对比度及读屏反馈使用可取得的交互或辅助技术证据。

每项发现保留任务步骤、版本、视口、数据状态、预期与实际。比较前后版本时保持条件一致，留下脱敏截图、录屏或可访问性树，同时记录交互结果。静态图片只能证明捕捉到的画面。没有设备、设计稿或运行入口时，给出可复核的静态发现和未验证的交互项。视觉偏好与妨碍任务的缺陷分列。

输出“页面及任务｜设备与状态｜实走结果｜通过／失败／未测｜证据｜具体改法或保留点”。交付到总看板的 03 行并附专项明细。对关键页面记录导航与入口发现、层级和反馈、桌面与移动布局、键盘和辅助技术。页面能打开只支持可达性。有问题时定位控件与复现步骤。即使没有发布阻断项也展示实际检查、一般体验问题和有观察依据的改进机会。缺少真机或用户证据时标出边界。留存可共享的实拍或实际界面截图，有前后版本时在相同条件对照。已获修复授权时按项目设计语言修正并复走完整路径。新增埋点、上传截图或改变品牌规范须在当前授权内。
```
